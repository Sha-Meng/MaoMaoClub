# CatBar 调酒玩法开发指南

## 当前范围

CatBar 是 960×540、60 physics tick 的 2D 轻俯视像素酒吧。大厅现采用原创暖暗像素背景，形成后墙酒架、中央吧台、七个吧椅和前景三组卡座的层次；程序化热点、调酒师、打工猫与顾客仍位于独立表现层。已完成全景内配置驱动调酒、量取/加液/投冰/撒料/拖勺入杯搅拌/封盖/Shake/倒杯、调酒师与打工猫接力送达、一次性经营结算、卡座氛围循环，以及统一像素主题的手机和微信。玩家不再点击入口或切换调酒近景：启动大厅后即可从左右酒架和吧台陈列台直接拿取酒瓶、辅料、量酒器、Shake 杯、独立杯盖、长柄勺和成品杯。

调酒 3C 采用全景场景直取：五种基酒分布在左右酒架，辅料和器具位于吧台实体陈列台；按住后原锚点留空，合法投放、非法释放或清空当前杯后归位。全景中的系统鼠标替换为双帧猫爪，图集旋转 180° 后空闲时张开、抓取时合拢；手机取得焦点时恢复系统鼠标。调酒师、打工猫及当前在场顾客也可被抱起；真实角色节点会在抓取期间隐藏，释放到开放 Shake 杯时加入一份稳定原料 `animal_droppings`（“动物的神秘馈赠”）。角色代理先蹲下，排泄物会以可见抛落进入杯口并产生落杯飞溅，随后角色左右刨动三次、扬起猫砂尘粒，最后移动回原锚点并恢复真实场景节点。整段表现期间锁定其他拖拽和手机入口。该趣味原料暂不属于正式配方。

首批可制作配方为“月夜猫语”：月光金酒 30 ml、暮色甜酒 30 ml、透明冰块 2 块、猫薄荷香料 1 份。两种基酒都必须先拖到量酒器量取，再把量酒器拖到 Shake 杯；完成搅拌、拖盖封杯、Shake 后，把 Shake 杯拖到月牙浅碟杯出杯。CatBar 杯体按物理帧读取与 Shake 实验相同的粒子/冰块局部只读快照，所以液体会随拖拽惯性晃动并在松手后衰减回稳；剂量和品质仍由领域命令日志决定，不随粒子档位变化。

容器表现与业务状态同步：量酒器转空后不能再次拿起倾倒；Shake 杯液位按 300 ml 容量计算，颜色由杯中基酒按剂量加权，运动粒子限制在锥形杯体内；杯盖按生成素材的实际可见底沿贴合杯口。出杯时月牙浅碟杯会按 180 ml 容量显示实际酒液量和同一加权颜色，并在短暂展示后进入送餐。

默认吧台内容包括五种基酒（月光金酒、暮色甜酒、落日威士忌、破晓伏特加、黎明白朗姆）、三种工具（Shake 杯、量酒器、长柄勺）和三种辅料（冰块、猫薄荷香料、特级鱼油）。后三种新增基酒暂时复用透明或琥珀流体模拟，但业务 ID、瓶身、颜色与风味标签彼此独立。

## 目录边界

- `features/cat_bar/bartending/`：内容 Resource、领域状态、策略、流体适配和工作台。
- `features/cat_bar/camera/`：场景模式和 Camera2D 预设。
- `features/cat_bar/service/`：送达与经营闭环。
- `features/cat_bar/patrons/`：不产生订单的氛围顾客。
- `features/phone/`：手机壳与微信领域/UI。
- `assets/cat_bar/`：可导入运行时资产；`art_source/cat_bar/` 只存美术源文件并由 `.gdignore` 隔离。

跨模块只传稳定 ID、命令、结果和可序列化快照。不得把 Node、Texture 或 Resource 实例写入存档，也不得让 CatBar 反向修改流体求解器内部数组。

## 新增调酒内容

新增器具或原料时，先实现/复用通用交互策略，再创建内容 `.tres` 并放入 catalog 和工作台槽位。新增交互应通过 `InteractionExecutorRegistry` 注册策略，不把业务判断写在 Button 回调。新增配方只引用稳定内容/交互 ID，并为剂量、容差、顺序、杯型和品质阈值配置步骤。

任何新运行时图片都必须加入 `asset_manifest.json`。像素纹理关闭过滤与 mipmap，尺寸必须是单帧整数倍，锚点必须落在单帧内；最终替换占位图时保持资产 ID 不变。本轮生成大厅、两款酒瓶、长柄勺和 2×2 统一猫角色图集均登记为 `PROJECT_GENERATED_REVIEW_REQUIRED`，可用于开发验证，发布前仍需人工美术与授权复核。角色图集四格顺序固定为调酒师、打工猫、夜猫客、下班猫，场景/顾客 Resource 通过纹理区域配置选择角色，业务控制器不硬编码图片路径。

## 微信内容编写

联系人定义包含稳定 ID、显示名、头像 ID、关系标签、解锁事件、简介、兴趣、爱好、人格特征、回复风格、口头禅和四类回复语料。联系人页双击条目进入会话；玩家发送非空文本后，离线回复生成器会按问候、提问、兴趣关键词或普通对话分类并立即回复。回复只依赖联系人配置与独立消息序列，不在 UI 中硬编码角色 ID。

消息/朋友圈模板配置作者集合、触发标签、权重、冷却与互斥键。新存档会确定性预生成五条初始朋友圈；生成后把作者、文案、图片、类别和时间写成实例，所以调整模板不会改写旧历史。玩家消息、好友秒回和已读变化会随微信状态触发正常存档。

订单送达、新一天或认识顾客通过唯一事件 ID 提交。UI 不自行生成内容；消息已读会同步总角标。消息、朋友圈和已处理事件都有容量上限。

## 存档与兼容

`SaveService` v2 保留 v1 的经济和窗口字段，新增 `bartending`、`wechat`、`content_unlocks` 分区。v1 自动补默认分区；未知稳定 ID 被过滤，废弃 ID 可通过映射迁移，单个损坏分区只回退自身。

## 手工测试步骤

1. 在 Godot 4.7.1 中打开项目，直接运行 `features/cat_bar/cat_bar.tscn`；确认大厅能看到暖木酒架、中央长吧台、七个吧椅、三个前景卡座、左侧霓虹猫标与右侧唱片机，且画面没有参考图中的品牌文字。
2. 启动后不要点击任何入口；确认全景中左右酒架、辅料陈列台和工具陈列台上的物件已经可以直接悬停和抓取，且不存在“点击进入调酒台”热点或镜头切换。
3. 确认全景中直接摆放五种基酒、三种辅料、量酒器、Shake 杯、独立杯盖、长柄勺和成品杯。悬停每种基酒，确认局部信息卡显示名字、30 ml 剂量和风味；悬停 Shake 杯应显示当前内容物与毫升数。
4. 在未完成成品时按 `Esc`，确认当前杯被清空但画面仍停留在全景，所有物件回到原位且可立即开始下一杯。
5. 确认五种基酒分布在左右酒架并显示不同瓶型，辅料、Shake 杯、量酒器、独立杯盖、长柄勺和月牙浅碟杯位于吧台台面。调酒焦点内应显示开放猫爪，按住物件后切换为抓握猫爪且原锚点留空。拖起任一基酒时量酒器描边，合法释放后播放倾倒并显示量酒器液位；再拖量酒器时 Shake 杯描边，释放后杯内出现对应液体。非法位置释放应归位且剂量不变。
6. 抓起调酒师、打工猫或当前顾客时，确认其原场景节点消失且同一角色随猫爪移动；在 Shake 杯外松手不会增加内容。在开放 Shake 杯上方松手后，确认角色先蹲下、排泄物清晰落入杯口并出现落杯粒子，然后左右刨动三次并扬起猫砂尘粒；动画期间不能抓取第二个对象或打开手机，结束后杯中只记录一份 `animal_droppings`，角色移动回原位。
7. 加入任意内容后拖动杯盖到 Shake 杯；确认封盖后杯盖从桌面消失、杯口闭合，Shake 杯描边并轻微抖动。按住 Shake 杯左右/上下往复移动；确认杯体位移保持在吧台范围，液体粒子和冰块相对杯体晃动。松手后杯体回到原位，液体继续短暂衰减并保持在杯内。
8. 按配方完成倒酒；确认调酒物件在服务阶段暂时锁定，调酒师先把成品摆在吧台交接点，打工猫随后拿走酒杯并移动到目标卡座；送达后全景物件自动恢复并开始下一杯。金币、服务数与研发材料只能在卡座放杯后结算一次。
9. 在大厅同时观察调酒师、绿色围裙打工猫、紫色夜猫客和蓝灰下班猫；确认四者头身比例、像素颗粒、轮廓和暖色受光一致，同时服装与托盘能区分职责。
10. 点击右下角 `CAT PHONE`，确认手机主页使用深色机身、暖金边框；微信为绿色可用入口，打车/小红书/拍照显示“即将开放”但点击会给出提示。
11. 打开微信并切换消息、联系人、朋友圈；确认页签高亮、卡片可滚动、朋友圈至少有三条且至少两种类别。关闭再打开手机，内容顺序不能变化。
12. 在联系人页双击店长猫、打工猫或酒吧常客名菜；应自动切到消息页对应会话。输入“你好”“怎么调经典鸡尾酒？”或联系人兴趣词并发送，应立即出现绿色“我”气泡和联系人回复；只输入空格不能发送。
13. 分别和三个联系人聊天，观察店长猫简洁克制、打工猫活泼吐槽、名菜温柔有画面感的差异。完成一次正常存档/重启后，聊天方向、顺序和朋友圈应恢复。

## 自动验证命令

在仓库根目录以 Godot 4.7.1 console 执行对应测试脚本。自动门禁包括粒子流体、Shake Lab、CatBar/微信、资产校验、性能和稳定性。GPU 截图脚本除手机页面外，还会输出 `.work/cat_bar_overview.png`、`.work/cat_bar_direct_bartending.png`、`.work/cat_bar_drag_animal.png`、`.work/cat_bar_animal_droppings.png`、`.work/cat_bar_bury_litter.png`、`.work/cat_bar_drag_spirit.png`、`.work/cat_bar_drag_jigger.png`、`.work/cat_bar_drag_lid.png`、`.work/cat_bar_shake.png`、`.work/cat_bar_shake_reverse.png`、`.work/cat_bar_service_handoff.png` 和 `.work/cat_bar_worker_delivery.png`，可并排检查全景直取、场景动物离位、掉落入杯、埋猫砂反馈、目标描边、流体位移与服务阶段。

已知环境提示：Windows 沙箱中可能无法读取根证书或写入 `user://`，生产桌面运行不受该测试沙箱限制。生成式美术目前是开发期素材；音效、四类猫的完整逐帧动画和全量酒具仍需后续替换。
