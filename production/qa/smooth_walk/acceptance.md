# 完整人物步态平滑验收

> 本轮体验验收被后续用户反馈否定：仍滑步、重影，松鼠切换闪烁。以下数值只证明当时检查项通过，未验证脚底世界接触。当前运行方案和新证据见 `../grounded_walk/acceptance.md`。

日期：2026-10-17。Godot 4.6.3 stable / 7d41c59c4，Windows Compatibility，RTX 3060。

## 结果

- 双步周期不再误用单步长度，实际业务速度约 0.58–1.14 周期/秒，原世界移动速度保持。
- 八个完整人物原画阶段整身等比注册，并通过双向运动补偿烘焙为 32 帧，覆盖第 7 原画回到第 0 原画。未重新拆分手脚，坐姿和喝酒未替换。
- 48 项单元/集成用例、3832 个断言通过；包含 15/30/60 FPS 同相位、真实速度范围、停步/反向/拖动、全部 320 个补间阶段无裁切/大块断开，及原营业/存档/编辑回归。新增补间连通检查曾检出狗角色第 1、17 帧残影，修正位移逆映射重复迭代后通过，未放宽阈值。
- GPU 真实时间录制十种人物各 132 帧，总 1320 帧：30 FPS 向右 2 秒、停止 0.4 秒、向左 2 秒；同图原尺寸浅底及两倍深底。原 PNG 在 `frames/`，GIF 时间用 30/30/40 ms 近似，累计时长 4.4 秒。
- 相邻帧预乘 RGBA 平均绝对差的最大值为原硬切阶段的 32.0%–36.3%，包含首尾接缝。该指标表示单次图像跳变减少，不单独证明美术动作自然。编码工具将大于原硬切跳变 60% 视作回归并返回失败。
- 原姿态和饮用 GPU 回归通过；160 完整身体样本无大块分离，36 坐姿样本脚底漂移均为 0。正式场景平均处理 7.57 ms、最大 10.74 ms，90 帧无状态约束错误，透明和置顶检查通过。

## 人工复看与限制

复看注册原画、重采样图集和实际渲染样本，重点检查店长持杯、服务员持盘、兔子手脚及循环尾段。新效果保留原完整人物的连接和比例；补间在极细轮廓可能轻微柔化，不能称为重新手绘了全部过渡。静帧与数值检查不等于用户对长期观看体验的最终确认。

正式桌面实例通过正常保存退出后重启，沿用玩家进度；未操作编辑器或重置存档。
