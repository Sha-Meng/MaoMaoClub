# 固定常驻置顶验收

日期：2026-10-17（Asia/Shanghai）

变更：`enforce-desktop-always-on-top`

## 问题与修复

用户反馈切换应用后酒馆被遮挡。现场截图显示旧版“置顶”按钮未选中；点击后按钮出现选中描边。旧设计把常驻作为可关闭开关，和用户要求的固定常驻不符。

现将该开关替换为“常驻”状态文字。窗口启动时固定置顶，失焦后延迟重申原生置顶标志，恢复焦点时再次应用。实现不调用窗口激活或抢焦点接口，并在最小化时直接跳过恢复逻辑。

## 自动检查

- Godot 版本：`4.6.3.stable.official.7d41c59c4`。
- 隔离副本、隔离 APPDATA / XDG 目录运行，使用真实 Windows DisplayServer 与 Compatibility 渲染器。
- 手动清除根窗口的置顶标志后，调用常驻策略，确认恢复为 true。
- 在根窗口缓存仍为 true 的情况下清除 DisplayServer 置顶标志，再触发失焦事件；两帧后原生标志恢复为 true。
- 最小化后调用常驻策略，确认窗口仍为 `MODE_MINIMIZED`，保存位置保持正常窗口坐标。
- 透明空白 alpha `0.0`，地台 alpha `0.380392163991928`；经济进度、位置与布局版本保存恢复相符。
- 原生检查退出码 0；随后模拟 60 秒自动营业运行退出码 0，无脚本错误。

## 真实应用切换

- 保存并关闭旧实例，使用 `tools/run_desktop.ps1` 启动新版，确认工具栏显示“常驻”，已没有置顶切换按钮。
- 激活 Godot 编辑器后，编辑器成为前台应用，酒馆工具栏仍覆盖在其窗口底部的重叠区域。
- 再激活 UGit，UGit 成为前台应用，酒馆金币面板与吧台仍覆盖在 UGit 的重叠区域；服务数从 424 继续增至 426。
- 本轮没有重置玩家经济数据或保存位置。

## 边界

常驻指普通 Windows 应用窗口之上的置顶层，不包含 Windows 安全桌面或其他应用的独占全屏。最小化、退出是玩家主动隐藏酒馆的入口。
