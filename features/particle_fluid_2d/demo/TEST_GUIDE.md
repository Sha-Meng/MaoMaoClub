# 2D 粒子流体验收指南（Godot 4.7.1）

## 先运行哪个场景

工程提供两个入口，它们使用同一套六个测试用例：

- `particle_fluid_demo.tscn`：打开后自动晃杯，适合先看效果；默认只有 60 个粒子，不再使用旧版 800 粒子压力场景。
- `particle_fluid_test_lab.tscn`：打开后保持静止，适合逐项验收和自定义配方。

两者都不依赖主场景、Autoload 或项目 InputMap。请使用 Godot `4.7.1.stable.official.a13da4feb`。

## 在 Godot 编辑器中启动

### 第一次快速演示

1. 打开 Godot 4.7.1，在项目管理器中导入并打开 `D:\felixzou\MaoMaoClub\project.godot`。
2. 等待右下角资源导入进度结束。如果脚本编辑器仍显示旧报错，执行顶部菜单“项目 → 重新加载当前项目”。
3. 在左下角 **FileSystem** 面板依次展开 `features → particle_fluid_2d → demo`。
4. 双击 `particle_fluid_demo.tscn`。
5. 按 `F6`，或点击编辑器右上角“运行当前场景”按钮。不要按 `F5`；`F5` 会运行整个项目的主场景。
6. 运行窗口应约为 1200×700。左侧是杯子，右侧是“验收/构造”面板。演示会自动左右晃杯；按 `B` 可停止或恢复自动演示。

### 逐项手动测试

1. 先停止当前运行场景（`F8`）。
2. 在 FileSystem 中双击 `particle_fluid_test_lab.tscn`。
3. 按 `F6`。实验室默认不自动晃杯，方便逐项观察。
4. 保持右侧 **验收** 页签打开。每次切换用例后，上方都会显示该用例的“步骤”和“通过”条件。

如果运行窗口太小导致按钮被遮挡，请拖大窗口；右侧页签内部可以滚动。

## 通用操作

可以点击右侧按钮，也可以在运行窗口获得焦点后使用快捷键：

| 按键 | 操作 | 预期 |
|---|---|---|
| `1`–`6` | 切换六个内置用例 | 杯子、液体、刚体和指标全部重置 |
| `A` / `D` | 向左/右晃杯 | 液体因惯性滞后并回荡 |
| `Q` / `E` | 向左/右倾杯 | 重力仍朝屏幕下方，杯口保持开放 |
| `Space` | 液体短时上冲 | 只持续约 0.2 秒，之后恢复正常重力 |
| `B` | 开关自动演示 | 每约 1.8 秒自动交替晃杯 |
| `M` | 切换“光学场/直接粒子” | 只改变显示，不改变物理运动 |
| `V` | 隐藏/恢复流体渲染 | 隐藏后求解仍继续，恢复后状态应已前进 |
| `P` | 暂停/继续求解 | 暂停期间粒子状态不再推进 |
| `R` | 重置当前用例 | 回到该用例确定的初始状态 |

## 六个测试用例

### 用例 1：透明混色

1. 点击“1 透明混色”或按 `1`。
2. 静置约 2 秒，观察红色与蓝色液体的接触区。
3. 交替按 `A`、`D`，每次约 0.5–1 秒，共三轮。
4. 按 `M` 切换一次渲染，再按一次切回光学场。

通过标准：接触区逐渐形成比普通 RGB 平均更深的减色混合；厚处颜色更深、薄处更透明；光学场有轻微高光和背景折射；切换渲染模式不会让粒子位置跳变。

### 用例 2：黏度对比

1. 点击“2 黏度对比”或按 `2`。
2. 按一次 `Space`，观察橙色低黏基酒和紫色高黏糖浆的响应。
3. 再交替按 `A`、`D` 两到三轮。

通过标准：橙色液体响应更快、回荡更明显；紫色糖浆形变和回流更慢；两者都不穿过杯壁，速度不会突然爆炸。

### 用例 3：密度分层

1. 点击“3 密度分层”或按 `3`。
2. 初始时高密度蓝液位于低密度黄液上方，这是刻意安排的非稳定状态。
3. 按 `B` 开启自动演示，或手动交替按 `A`、`D`。
4. 观察 15–30 秒，然后按 `B` 停止自动演示。

通过标准：蓝色高密度液体总体有下沉趋势，黄色低密度液体总体有上移趋势。粗粒子界面允许模糊，不要求形成精细平直分层；不得出现飞出屏幕、非有限值或红色状态提示。

### 用例 4：胶体浑浊

1. 点击“4 胶体浑浊”或按 `4`。
2. 先不操作，比较清澈蓝液与粉色胶体的透明度。
3. 按 `Space`，再用 `A`、`D` 晃杯。
4. 按 `M` 对比直接粒子模式，再切回光学场。

通过标准：蓝液更透明、更灵活；粉色胶体更浑浊、流动更迟缓；重叠和较厚区域会加深；画面没有黑色矩形、整屏闪烁或上一帧残影。

### 用例 5：冰块浮起

1. 点击“5 冰块浮起”或按 `5`。
2. 不操作，等待 5–10 秒，让 7 kg 冰块落入液体并回升。
3. 观察右侧指标末尾的“浸没”百分比。
4. 稳定后用 `A`、`D` 晃杯。

通过标准：冰块最终浮起并保持部分浸没；浸没率连续变化；冰块和液体没有瞬移、穿墙或持续增能。

### 用例 6：重物下沉

1. 点击“6 重物下沉”或按 `6`。
2. 等待 24 kg 重物穿过液面并落到杯底。
3. 用 `A`、`D` 晃杯，观察底部接触。

通过标准：重物不能被最大排水浮力托住，最终由杯底承托；不得悬空、弹飞或穿透杯底。

## 怎样读右侧实时指标

右侧显示 `FPS`、`物理 ms`、`粒子`、`子步`、`密度误差`、`最大速度`和`邻居`：

- 六个内置用例都应显示约 60 个粒子，绝不能超过 136；这是交互档的硬预算。
- `子步`不得超过 `8`。内置用例通常约为 `3/8`。
- 在当前 Ryzen 9 9950X 的 Godot 4.7.1 headless 基准中，60 粒子求解平均约 4.50 ms；编辑器加上光学渲染后会略高，偶发单帧峰值不算失败。
- 绿色“数值有限”表示当前步健康；黄色表示软诊断，需要记录触发操作；红色提示、非有限值或粒子数超预算视为失败。
- 若 FPS 很低，先按 `M` 切到直接粒子，再按 `V` 隐藏渲染：只有渲染关闭后明显恢复，问题偏向光学显示；两种模式都慢则记录“物理 ms”和粒子数。
- 光学场中的液体必须在深色网格背景上呈现清晰的红、蓝或配方颜色；若只有冰块/重物而完全看不到液体，先执行“项目 → 重新加载当前项目”，再重新按 `F6`，以确保 Godot 载入了修复后的 Shader。
- 默认“光学场”模式的液体内部不得露出规则网格孔洞；按 `M` 切到“直接粒子”后重新看到离散圆片属于正常诊断效果。
- 光学场会闭合被液体从两侧包围的稀疏内部暗孔；自由液面仍可有像素化起伏，但液体主体不应再呈现彼此分离的圆斑。
- 1200×700、60 粒子内置用例的验收目标为至少 45 FPS；若持续低于 45，记录光学场/直接粒子两种模式的 FPS 与“物理 ms”。
- 水感检查：在用例 `1`、`5` 或 `6` 中连续短按 `A/D`。普通液体应出现层间错位和左右液面高度差，松手后继续短暂晃动再耗散；如果整团同步位移并反复弹回，则视为果冻感回归。
- 静置检查：重置用例后等待约 2 秒，右侧应显示“已静稳”，最大速度接近 `0.00 m/s`，液面不再持续像素抖动。再按 `Space`、`A/D` 或 `Q/E` 时必须立即退出静稳并恢复流动，停止输入后重新收敛。

建议每个用例至少运行 30 秒，最后任选一个用例连续运行 60 秒，并多次执行 `A/D/Q/E/Space/M/V/P`。期间不得出现红色提示或崩溃。

## 自定义杯子和液体

1. 切换右侧 **构造** 页签。
2. 在“宽度”“高度”中输入新尺寸，点击“应用杯子尺寸并重置”。
3. 设置体积、颜色、颜色浓度和浑浊度，点击“添加为新液体”。
4. 从“选择已有液体”下拉框选择配方，可更新或删除。
5. 回到 **验收** 页签查看实时粒子数和健康状态。

宽度允许 2.0–6.4 m，高度允许 2.0–4.5 m。每个粗粒子约代表 4 L，输入体积会向上量化为完整粒子；若总容量不足，尺寸或配方修改应被拒绝，已有液体不能丢失。自定义配置也建议保持不超过 136 粒子，以维持交互性能。
