# 猫猫酒吧：场景内实体调酒 UX 规格

## 体验目标

玩家应在大厅全景中直接从酒架和吧台拿起真实物件完成一杯酒，不需要点击入口、切换镜头或打开菜单。每个阶段只突出当前可接受的目标，让第一次游玩的玩家无需阅读长教程也能完成操作。

## 画面布局

- 后墙：五种基酒分列左右酒架，酒架底板遮住背景烘焙瓶身，抓起后留下可见空槽。
- 左侧吧台：冰块、猫薄荷香料、特级鱼油放在木质辅料台。
- 右侧吧台：量酒器、Shake 杯、独立杯盖、长柄勺和成品杯放在木质工具台。
- 左上：仅在悬停时出现的物件信息卡。
- 顶部中央：横向紧凑配方便签，可见但不遮挡酒架与角色。
- 下方：单行操作反馈与 `Esc 清空本杯` 提示。
- 指针：双帧猫爪图集整体旋转 180°，空闲张开、按住对象时抓握。

## 引导节奏

1. 拿起基酒瓶，量酒器发光并显示“拖到量酒器”。
2. 量酒器有液体后拿起它，Shake 杯发光并显示“倒入 Shake 杯”。
3. 拿起辅料，Shake 杯发光；拿起杯盖，Shake 杯再次发光。
4. 封盖后 Shake 杯短促抖动并保持弱光，提示可按住摇制。
5. 有效 Shake 后拿起 Shake 杯，成品杯发光，完成最后倒杯。

## 动物原料反馈节奏

1. 动物释放到开放 Shake 杯后，先在杯口上方快速落位并蹲下，让玩家明确动作来源。
2. 排泄物图标从动物下方落入杯口，缩小并以暖色飞溅确认命中；领域层只增加一份 `animal_droppings`。
3. 动物在杯口上方左右刨动三轮，每次刨动扬起像素猫砂尘粒，形成“认真埋猫砂”的可读动作。
4. 动物代理移动回原锚点后才恢复真实场景节点；整段动画锁定其他拖拽和手机入口，避免重复提交或角色瞬移。

## 异常与恢复

- 空量酒器、空 Shake 杯、未封盖 Shake、未完成 Shake 就倒杯都给出具体原因。
- 非法释放只触发回弹，不能产生剂量、步骤日志或库存变化。
- 动画中拒绝第二次拖拽，防止重复提交。
- 按 `Esc` 后清空当前杯，所有物件回到初始位置，高亮和悬停卡清空；画面保持大厅全景。
