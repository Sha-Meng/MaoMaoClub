# 猫猫 Club 双 MVP 简报

日期：2026-07-01

## 设定来源

当前项目初步想法是一款桌面挂机模拟经营游戏：玩家在桌面边缘经营一家夜间营地小酒馆，猫猫员工作为主要陪伴与劳动力，动物顾客到店消费，订单带来金币和经营值，顾客离开时可能掉落调酒材料，玩家再通过材料研发酒水并改变后续客群与收益。

核心链路：

> 猫猫上岗 -> 顾客消费 -> 收益增长 -> 掉落材料 -> 研发酒单 -> 改变客群 -> 收益进一步增长

## 双 MVP 拆分原则

项目先拆成两个互相衔接、但分别验收的 MVP。

### MVP 1：桌面挂机体验

这个 MVP 验证游戏作为桌面陪伴小世界是否成立。重点是酒馆贴在桌面边缘运行、猫猫在任务栏上方活动、玩家可以点击和拖拽猫猫、顾客能自然进店消费并离开、成功营业能产生基础金币和经营值反馈。

这个 MVP 不要求完整调酒研发和酒单策略，只需要证明“桌面上有一个活着的小酒馆”足够可爱、清楚、可持续观看。

### MVP 2：调酒经营体验

这个 MVP 验证调酒是否能形成真正的经营决策。重点是顾客掉落材料、材料研发酒水、今日菜单影响顾客类型或消费结果、玩家能通过调整酒单观察到客群和收益变化。

这个 MVP 可以复用桌面挂机的基础场景与顾客流，但要作为独立 OpenSpec 变更 跟进，避免把“陪伴感是否成立”和“调酒策略是否成立”混在一起判断。
