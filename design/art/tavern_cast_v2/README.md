## 版本关系

- 本轮根据用户反馈修改“体型相近、统一眯眼微笑”的问题。保留 V1 顾客物种与服装，不覆盖历史图。
- 店长身份、金链、背心、圆腹及自然比例沿用 `manager_proportions_v2.png`；半睁眼用于表现放松与关注，眯眼笑仍可作为情境表情。
- 顾客的临时称呼为阿栗、阿领、慢慢、绯绯、小绘、夜豆，不改变稳定角色 ID 或既有材料映射。
- 图中相对高矮用于讨论，没有锁定游戏资源尺寸、帧数、拼图布局或最终常驻像素高度。
- 继续使用已选桌面效果比例；两张概念板不是屏幕占比示意。

## 目视检查

- 六位顾客完整身体及主要识别道具可见；瘦高狗、轻巧松鼠、宽胖水豚形成首批对比。
- 常态脸已区分睁眼、半睁眼、眉位、嘴型与视线；不是六位统一闭眼笑。小样中的笑和惊讶属于情境表情。
- 狐狸、小兔与浣熊通过站姿、耳位、躯干与手持物进一步区分；正式分件时仍需检查去色后的轮廓。
- 三位猫均有完整身体，店长保持既定服装与身份，店员没有复制金链和敞腹造型。
- 团队图包含放大行为小样，不能把它们与上方全身主图当成同尺寸图集帧。
- 中文标签已核对主要角色和性格信息；正式资源的名字用稳定 ID 管理，不依赖图中文字。
