## 角色分工建议

沿用当前“三只猫猫”的规模，建议分为一位店长和两位员工：深色猫担当调酒员，浅色猫担当服务员。颜色与岗位是本轮制作建议，未成为已实施岗位系统。店长的既定方向是自由游走与顾客闲聊，不固定占用吧台工作位。

## 使用边界与检查

- 与用户选定的桌面效果图保持暖色手绘 2D 方向，不改变既定占屏比例。
- 六位物种、主要服装、尾巴、耳朵和全身轮廓已目视检查；中文标签及分批信息可读。
- 图中的酒杯、包、手机和画本是角色概念道具。正式制作时要拆层，不能把永久握杯的站姿直接当所有动作的基础。
- 六位都采用放松表情；量产时需补睁眼、说话和倾听表情，避免所有顾客一直眯眼。
- 此图没有透明抠图、坐姿、背面、逐帧一致性或动画时序保证；不能直接切成可运行的动画资源。
- 放在 `.gdignore` 目录中，仅作为讨论来源。
