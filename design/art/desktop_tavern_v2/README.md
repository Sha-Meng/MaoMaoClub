## 本轮变化

1. 店长自由游走，可停下来与顾客闲聊。
2. 店铺、角色和桌椅均支持自由拖动摆位，方向为轻量 UGC。
3. 先按小尺寸方向制作候选，最终占屏尺度以用户选定的 `desktop_idle_selected_v2.png` 为准。
4. 店长头部相对缩小、躯干与四肢适当拉长，腹部改为更连贯的圆润体积；保留眯眼、粗项链、背心、卷尾和酒杯。
5. 不覆盖 V1 原图；V1 作为设计历史保留。

## 历史小尺寸候选的尺度核对

在全尺寸常驻效果图中，对右下游戏对象的暖色主体像素进行只读边界检查：横向约 x=1362–1604，纵向约 y=789–861，高约 73 像素；73 / 941 ≈ 7.76%。这是含店铺主体的视觉高度估算，非运行时窗口尺寸或透明留白面积。上方标题是展示标注，不属于游戏常驻区域。

占比暂按屏幕高度解读，未按面积计算。实际像素应在实施时随屏幕分辨率和 DPI 校准。
