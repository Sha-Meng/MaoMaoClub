## 原稿保留

1. 任务栏上沿作为共同落地线，店长在横向活动。
2. 开放式小酒摊与周边桌椅形成桌面边缘的小世界。
3. 顾客可以坐在椅子上安静待机。
4. 店长保留大圆脸、眯眼、胡须、粗项链、圆肚子、肚脐、短腿、卷尾与酒杯。

## 本轮新增的视觉提案

- 暖色手绘 2D，细棕色轮廓与柔和体积，不采用像素风或写实 3D。
- 奶白店长、深色开襟背心、金项链；苔绿棚顶、暖木吧台、琥珀灯光。
- 店长在摊位外活动，另外两只员工猫在吧台内工作，共三只猫。这是角色分工建议，不是原稿明示规则。
- 常驻信息集中于店铺附近，长条 HUD 改为按需出现的轻量入口。
- 效果图为看清细节采用放大比例，尚未锁定真实占屏尺寸；交互图建议常态高度为屏幕的 20–25%，需用户确认。

图中的桌面底色、任务栏图标、时钟和数字都是展示用占位，并非真实桌面截屏或当前经营进度。运行时应使用透明底素材，不能把整张效果图当游戏背景。
