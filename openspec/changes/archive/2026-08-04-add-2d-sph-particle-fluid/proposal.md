## Why

项目需要一套可复用、可验证的 2D 粒子流体能力，用于表现倒入容器、混色、晃动与漂浮物等核心交互；目前项目尚无流体规格，若直接与具体玩法绑定实现，将难以独立调参与测试，也会放大后续性能和物理一致性风险。

## What Changes

- 新增与业务玩法解耦的 2D 粒子流体模块，对外只暴露配置、命令、查询和信号接口，数值状态不依赖具体关卡、调酒、角色或 UI。
- 采用弱可压缩 SPH（WCSPH）离散流体，定义核函数、邻域搜索、密度/压力、黏性、重力、时间步长和稳定性约束，并提供确定性手动步进接口。
- 每个粒子携带线性光空间颜色与混合属性；相邻粒子通过扩散/对流交换颜色，再在渲染边界转换为 sRGB，支持多种流体混合后的连续颜色变化。
- 支持由线段或凸多边形边界描述的静态及运动容器，处理不可穿透、边界反弹、摩擦与无滑移近似，并将容器的位移、旋转、线加速度和角加速度转换为流体参考系中的惯性力。
- 支持规则、均质 2D 刚体与流体交互；通过浸没采样估算排水面积、浮力、流体阻力和扭矩，使冰块等对象能够漂浮、下沉、倾斜并反作用于流体。
- 新增覆盖数值核、守恒/稳定性、混色、容器约束、外力响应、浮力与性能基线的自动化测试和演示场景。
- 第一版以“游戏级视觉可信与稳定可调”为目标，不承诺工程 CFD 精度、任意凹多边形刚体、自由液面网格重建或 GPU Compute 求解。

## Capabilities

### New Capabilities

- `particle-fluid-2d`: 定义独立 2D SPH 流体模块、粒子状态、光学颜色混合、容器边界、运动参考系外力、稳定性和可测试接口。
- `fluid-object-interaction`: 定义规则均质对象的浸没检测、阿基米德浮力、阻力/扭矩、双向动量交换及漂浮/下沉行为。

### Modified Capabilities

无。

## Impact

- Code: 计划新增 `features/particle_fluid_2d/`，内部按数值核心、Godot 适配、渲染和测试夹具分层；现有业务模块只通过公开适配器使用该能力。
- Tests: 计划新增无渲染确定性单元测试、小型场景集成测试、长期稳定性测试和粒子规模性能基线。
- APIs: 新增流体配置、粒子批量注入/移除、容器运动输入、外力输入、规则刚体注册/注销、状态快照与事件接口。
- Dependencies: 面向 Godot 4.6.3 stable 与 Windows；优先使用项目既有测试设施，若仓库尚无可用 Godot 测试框架，则在实施前按项目流程单独确认是否引入第三方依赖。
- Systems: 不修改当前主场景职责，不要求全局 Autoload，不直接依赖调酒、经济、角色、UI 或存档系统。
