# Godot 4.7.1 升级设计

## 决策

- 目标版本固定为本机实测的 `4.7.1.stable.official.a13da4feb`。
- Windows 本地验证程序为
  `D:\Godot_v4.7.1-stable_win64.exe\Godot_v4.7.1-stable_win64_console.exe`。
- 不修改已归档变更或旧测试证据中的版本文字；那些内容记录的是当时事实。
- 当前 specs 与仍生效的工作流文档更新到 4.7.1。
- 先按兼容模式迁移，只有后续需求确实需要时才采用 4.7.1 新 API。

## 风险

- 4.7.1 的 Shader、SubViewport、GDScript 解析或物理行为可能与 4.6.3 有细节差异。
- 同一项目同时由两个 Godot 主版本打开会争用 `.godot` 导入缓存；升级后只使用 4.7.1。
- 性能基线必须重新采样，不能直接把 4.6.3 数字当作 4.7.1 门禁。

## 验证

1. `--version` 必须输出精确构建。
2. headless editor 扫描无解析错误。
3. 默认、长稳、实验室冒烟和 demo 生命周期测试通过。
4. 重新记录实际交互粒子档的性能。
