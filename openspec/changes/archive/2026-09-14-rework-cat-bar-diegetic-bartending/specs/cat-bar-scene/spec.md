## MODIFIED Requirements

### Requirement: 全景与调酒近景镜头

系统 MUST 为全景与调酒近景提供具名相机构图预设，并 MUST 通过有界时长的平滑过渡进入和退出调酒台；过渡期间 MUST 阻止会造成重复状态切换的世界输入。过渡完成后，调酒内容 MUST 作为与近景背景对齐的实体物件出现，且 MUST NOT 显示独立完整调酒面板。

#### Scenario: 进入调酒模式

- **当** 玩家点击大厅吧台入口
- **那么** 镜头平滑拉近到调酒台
- **并且** 镜头过渡完成后隐藏入口按钮，显示与背景对齐的实体原料和工具
- **并且** 不显示独立的完整调酒面板或分类菜单

#### Scenario: 退出调酒模式

- **当** 玩家在未进入送餐锁定状态时按下 `Esc` 或点击局部返回按钮
- **那么** 临时调酒内容被清理，实体物件层隐藏，镜头返回大厅总览，入口按钮恢复
