# Cocktail Shaker Lab 规格增量

## ADDED Requirements

### Requirement: 独立业务模块

系统必须将调酒 Shake 测试的运行时代码放在独立功能目录中，只通过公开适配器依赖粒子流体模块。

#### Scenario: 检查目录边界

- **WHEN** 开发者检查 Shake 测试场景、配置和冰块代码
- **THEN** 这些文件位于 `features/cocktail_shaker_lab/`
- **AND** `features/particle_fluid_2d/` 不包含调酒业务代码

### Requirement: 按稳定 ID 关联的两层液体配置

系统必须使用 `FluidId` 枚举作为稳定 Key，将液体业务配置与粒子模拟配置分离。业务配置必须至少包含 ID 和名称；模拟配置必须包含底层完整粒子求解参数、加入体积、生成、物理、混合、染色和光学参数。

#### Scenario: 配置两种液体

- **WHEN** 业务目录和模拟配表包含两个具有唯一 `FluidId` 的 Resource
- **THEN** UI 显示两个可选液体名称
- **AND** 选中并加入液体时使用相同 ID 对应的模拟参数

#### Scenario: 使用真实水样例

- **WHEN** 开发者加载 20°C 水业务配置和水粒子模拟配置
- **THEN** 两者使用相同的 `FluidId.WATER`
- **AND** 真实物性与交互求解参数分别存放

### Requirement: 可封盖 Shake 杯

系统必须以空杯、无液体、无冰、未封盖状态启动，并通过 UI 分步加入内容及封盖。

#### Scenario: 构造测试内容

- **WHEN** 用户选择液体并点击增加液体、点击增加冰块、再点击封盖
- **THEN** 场景按配表增加对应粒子和一块冰
- **AND** 顶部流体边界与刚体碰撞壁在封盖后有效

### Requirement: 鼠标驱动 Shake

系统必须在 Shake 模式下使用鼠标左键拖动控制杯体二维运动，并以可配置灵敏度和最大幅度限制输入；再次点击 Shake 必须退出模式并复位杯体。

#### Scenario: 鼠标拖动摇杯

- **WHEN** 用户点击 Shake 后按住鼠标左键向任意二维方向移动
- **THEN** 杯体目标位移跟随鼠标方向并乘以灵敏度
- **AND** 位移和转角不会超过配置的最大幅度

#### Scenario: 结束 Shake

- **WHEN** 用户在 Shake 模式再次点击 Shake
- **THEN** 输入模式结束
- **AND** 杯体回到初始位置与初始转角

### Requirement: 封闭 Shake 不逸出

封盖后，无论鼠标输入速度和方向如何，液体粒子和冰块都不得越出闭合杯体；杯体不得越出配置的最大 Shake 位移。

#### Scenario: 极端鼠标输入

- **WHEN** Shake 模式收到远大于最大幅度的快速对角鼠标位移
- **THEN** 杯体位移被钳制在水平和垂直最大幅度内
- **AND** 所有液体粒子与冰块在后续物理步保持于闭合杯体内部

### Requirement: 从杯口向下加液

增加液体必须表现为从杯口向杯底加入，而不是直接在杯底生成。

#### Scenario: 点击增加液体

- **WHEN** 开口杯中点击增加液体
- **THEN** 新批次粒子在杯口内侧生成
- **AND** 新粒子具有向下初速度并在重力下落入杯中

#### Scenario: 封盖后尝试增加内容

- **WHEN** 杯盖已封闭
- **THEN** 增加液体和增加冰块操作被拒绝

### Requirement: 冰块测试

系统必须允许配置冰块数量、尺寸、密度、阻力、浮力、刚体阻尼、摩擦和反弹参数。冰块必须与杯壁及其他冰块发生刚体碰撞，并在 Shake 时获得可观察的运动量。

#### Scenario: 逐块加入冰块

- **WHEN** 用户点击增加冰块且尚未达到配置上限
- **THEN** 场景只创建一块刚体冰块
- **AND** 新冰块加入流体浮力适配器列表

#### Scenario: Shake 中冰块碰撞

- **WHEN** 封盖杯中存在至少两块冰并执行快速往复 Shake
- **THEN** 移动杯壁向冰块传递运动量
- **AND** 冰块与杯壁及彼此的碰撞保持有效
- **AND** 高速闭合约束不得把冰块速度直接清零

### Requirement: Shake 结束后快速静稳

系统必须在结束 Shake 并复位杯体后，使液体粒子和冰块在可配置的短时窗口内快速衰减运动，并在窗口后交由常规静置逻辑继续保持稳定。

#### Scenario: 结束 Shake

- **WHEN** 用户再次点击 Shake 结束高幅度往复运动
- **THEN** 杯体在物理帧内复位且容器运动历史被清除
- **AND** 液体平均速度与冰块速度持续下降
- **AND** 静稳窗口结束后液体不会因冰块微动而永久无法进入静置状态
