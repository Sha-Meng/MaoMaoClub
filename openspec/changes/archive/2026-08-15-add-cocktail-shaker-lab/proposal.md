# 变更提案：新增可配置的调酒 Shake 测试环境

## 背景

现有 `particle_fluid_2d` 实验室用于验证底层流体能力，不适合承载调酒业务流程。项目需要一个独立的 Shake 杯测试环境，用 Resource 配置多种液体、封盖、摇晃动作和冰块，并保留底层流体模块的通用性。

## 目标

- 新增独立的 `cocktail_shaker_lab` 功能目录，业务代码不进入 `particle_fluid_2d`。
- 将液体业务配置与粒子模拟配置拆为两张按稳定液体 ID 关联的 Inspector 可编辑配表。
- 将求解器、杯体、封盖、Shake 动作、冰块和显示参数开放为组合配置。
- 提供 20°C 真实水物性参考与交互模拟映射样例。
- 提供空杯启动的交互测试流程：选择并加入液体、逐块加入冰、封盖，再用鼠标拖动 Shake。
- 提供独立自动测试和编辑器操作说明。

## 非目标

- 不追求分子尺度或工程级流体精度。
- 不把真实水声速直接带入实时弱可压缩 SPH 求解。
- 不在本次变更中制作正式游戏 UI、美术资产或配方系统。

## 兼容性

- 引擎固定为 Godot 4.7.1 stable。
- 复用 `ParticleFluid2D`、`ContainerMotionAdapter2D` 和 `BuoyantBodyAdapter2D` 的公开接口。
- 不改变现有粒子流体 demo 与验收实验室的业务行为。
