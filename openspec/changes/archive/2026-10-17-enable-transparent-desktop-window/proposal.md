# 启用半透明桌面酒馆窗口

## 为什么要做

当前运行时只在启动后设置无边框，未启用原生逐像素透明，且酒馆绘制了覆盖整个窗口的不透明背景。玩家看到的仍是一张完整页面，与桌面挂机预期不符。用户已明确要求优先实现真正的无边框半透明桌面形态。

## 改动内容

- Windows 启动即启用无边框、逐像素透明和透明根视口，空白处显示下方桌面或应用。
- 使用 Compatibility 渲染器承载当前轻量 2D 酒馆；禁用不透明启动画面。
- 移除铺满窗口的背景，地台和操作面板采用局部半透明表现，角色保持清楚可见。
- 默认置顶，提供置顶开关、窗口拖动、最小化和保存后关闭入口。
- 首次启动贴近屏幕可用区域右下角；恢复旧存档时修正越界位置，保留经济进度。
- 提供独立启动脚本与编辑器运行说明，避免编辑器嵌入容器遮蔽透明效果。

## 影响范围

- 规格：新增 `desktop-window`，取代旧 MVP 文档中把真透明与置顶仅列为后续增强的窗口预期。
- 代码：`project.godot`、`app/`、`features/desktop_window/`、`features/persistence/`、`features/tavern_loop/`、`ui/hud/`。
- 工具与文档：独立启动脚本、README、项目上下文、旧 MVP 窗口说明。
- 验证：Godot 4.6.3 导入与运行检查、真实 Windows 窗口透明/移动/退出验收、隔离存档回归。
- 本次不实现调酒经营，也不引入原生扩展或承诺全窗口点击穿透。
