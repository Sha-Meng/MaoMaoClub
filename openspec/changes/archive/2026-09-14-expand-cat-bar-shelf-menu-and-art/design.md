# 设计说明

## 菜单与内容模型边界

内容仍由 `CatBarContentCatalog` 和稳定 ID 驱动。一级分类是工作台表现层对既有内容类别的投影，不把 UI 状态写入内容 Resource 或存档：液体原料映射为“基酒”，工具映射为“工具”，冰块与香料映射为“辅料”。目标酒杯继续作为调酒结果区域展示，不进入本轮三级分类。

二级菜单使用可滚动纵向列表，每项包含定宽图片区和名称；点击仍调用 `click_content(content_id)`，因此不改变命令、剂量和领域状态。长柄勺条目继续接收拖拽输入。

## 新酒液的流体兼容

当前 Shake 实验只提供透明与琥珀两套流体模拟。新增基酒拥有独立业务 ID、瓶身、颜色和风味标签，但暂时映射到现有兼容流体 ID；领域配方与存档仍按稳定原料 ID 区分，不由粒子模拟 ID 决定。

## 素材约束

素材使用透明背景、正交单物件构图和统一暖暗像素风，不包含品牌文字或水印。生成式素材标记为 `PROJECT_GENERATED_REVIEW_REQUIRED`，保持 nearest、无 mipmap，并在发布前接受人工美术审阅。
