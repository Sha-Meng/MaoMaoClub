# 恢复店长前后交替步态并对齐用户原型

## 原因

用户明确要求交叉走，并提供 exec-ddceb4ab-bb74-4ee8-b34e-b5da7e1f6879.png 作为原型效果参考。此前将“不偏女性化”解释为“双脚不能交叉”是错误的实现约束，本次撤销。用户期望正常步行的双腿前后交替与经过交叠，同时保留稳重感。

## 变更

- 以新参考的圆脸、短颈、厚腹、粗短腿和宽脚掌校准人物。
- 近远腿独立绑定，根部藏入宽腹内部，近腿使用顶点渐隐融合连接；固定近腿在前、远腿在后，避免共用身体平面限制交叉或拉扯腹部。
- 正常前后迈步、经过姿势和近远腿遮挡，不通过临时交换图层实现。
- 撤销最小水平脚距测试；改验双脚前后顺序在周期内交替、支撑锁地、遮挡与视觉连贯。
- 保留空手/持杯 8 个片段和独立 Godot 验证入口。

## 范围

店长样片、源稿、骨骼制作、测试及规格；正式营业和其他角色尚不迁移。
