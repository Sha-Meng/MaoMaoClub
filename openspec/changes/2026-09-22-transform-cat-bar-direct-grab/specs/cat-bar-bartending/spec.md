# cat-bar-bartending 规格增量

## ADDED Requirements

### Requirement: 场景直取式调酒输入

大厅全景 MUST 无需入口点击或镜头切换即可抓取场景内的基酒、调酒用具与可用动物；抓取开始后原锚点 MUST 留空，合法操作、非法释放、清空当前杯或调酒结束后对象 MUST 回到原锚点。合法目标高亮规则 MUST 与既有调酒流程一致。

#### Scenario: 从场景抓起基酒

- **WHEN** 玩家按住场景酒架上的基酒
- **THEN** 瓶子离开原锚点并随猫爪移动
- **AND** 量酒器使用既有合法目标高亮
- **AND** 操作结束后瓶子回到原锚点

#### Scenario: 非法位置释放

- **WHEN** 玩家把任一来源对象释放在非高亮区域
- **THEN** 不产生容器内容或动作日志
- **AND** 对象恢复到原锚点

### Requirement: 猫爪指针反馈

调酒焦点生效时 MUST 使用不会拦截输入的猫爪指针；空闲状态 MUST 显示开放猫爪，抓取期间 MUST 显示抓握猫爪，离开调酒焦点后 MUST 恢复系统鼠标。

#### Scenario: 抓起并释放对象

- **WHEN** 玩家按住可抓取对象后松开
- **THEN** 猫爪由开放帧切换为抓握帧并在结束后恢复开放帧

### Requirement: 动物作为调酒来源

调酒师、打工猫和当前在大厅中的顾客 MUST 可被抓取；抓取期间真实动物节点 MUST 从原处消失。释放到开放 Shake 杯时 MUST 只加入一份稳定原料 `animal_droppings`，并依次表现排泄物可见落入杯口、落杯命中反馈、动物左右刨动与猫砂尘粒；表现结束后动物 MUST 移动并回归原位。整段序列期间 MUST 锁定其他拖拽与手机入口。

#### Scenario: 抓取猫猫到 Shake 杯

- **WHEN** 玩家抓起场景猫猫并在开放 Shake 杯上方松开
- **THEN** 杯中增加一份动物掉落物原料
- **AND** 掉落动画结束不阻塞后续调酒
- **AND** 猫猫恢复到抓取前的场景锚点

#### Scenario: 取消动物抓取

- **WHEN** 玩家在杯外松手或按 Esc 退出
- **THEN** 不增加动物掉落物
- **AND** 所有被隐藏的动物节点恢复可见
