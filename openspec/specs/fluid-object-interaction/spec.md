## Requirements
### Requirement: 规则均质物体描述
流体对象交互能力 SHALL 支持圆形、矩形和凸多边形 2D 规则物体。每个对象描述 MUST 包含稳定 ID、世界姿态、线速度、角速度、质量、质心、转动惯量、有效厚度和均匀内部采样；数值核心 MUST 仅持有值快照而不持有业务 Node 或 RigidBody2D 引用。

#### Scenario: 注册均质矩形冰块
- **WHEN** 调用方提交一个具有合法尺寸、质量、有效厚度和刚体运动状态的矩形对象快照
- **THEN** 模块为该对象建立面积权重一致的浸没采样
- **AND** 后续力结果使用对象稳定 ID 返回

#### Scenario: 拒绝无效对象参数
- **WHEN** 对象质量、面积、有效厚度或转动惯量为零、负值或非有限值
- **THEN** 模块在参与求解前拒绝该对象描述
- **AND** 其他合法对象和流体仍可继续推进

### Requirement: 浸没状态可连续估算
模块 SHALL 使用流体邻域密度、覆盖度和对象内部面积样本估算浸没面积与排水体积。浸没率 MUST 随对象跨越自由表面连续变化，并 MUST 在阈值附近使用平滑判定以避免单个邻居变化导致力瞬间跳变。

#### Scenario: 对象缓慢进入水面
- **WHEN** 规则对象从自由表面上方缓慢向下移动直到完全浸没
- **THEN** 报告的浸没率从 0 连续增加到接近 1
- **AND** 浮力不会因单个采样点切换而产生无界脉冲

#### Scenario: 对象离开全部流体邻域
- **WHEN** 对象所有采样点都不再有有效流体覆盖
- **THEN** 模块返回零浸没率和零流体浮力/阻力
- **AND** 模块不会替代 Godot 刚体自身的重力

### Requirement: 浮力符合阿基米德原理
模块 SHALL 按局部流体密度、重力和排开体积计算方向与重力相反的浮力。完全浸没时浮力大小 MUST 近似等于排开流体的重量；部分浸没时 MUST 只计入浸没排水体积。

#### Scenario: 低密度物体达到漂浮平衡
- **WHEN** 均质物体密度低于流体有效密度并从水面上方落入静水
- **THEN** 对象在阻尼后达到部分浸没的漂浮状态
- **AND** 稳态浸没面积比例在配置容差内接近 `object_density / fluid_density`

#### Scenario: 高密度物体下沉
- **WHEN** 均质物体密度高于流体有效密度且没有其他支撑力
- **THEN** 最大浮力不足以抵消对象重量
- **AND** 对象继续向重力方向下沉直到遇到容器或离开流体

#### Scenario: 近等密度物体近似悬浮
- **WHEN** 均质物体密度在容差内等于流体有效密度且完全浸没
- **THEN** 对象的重量与浮力在容差内平衡
- **AND** 无其他相对流动时不会产生显著持续竖直加速度

### Requirement: 流体阻力和恢复扭矩
模块 SHALL 根据对象采样点与局部流体的相对速度计算有限流体阻力，并 SHALL 依据力相对质心的力臂累计扭矩。阻力 MUST 反对相对运动且不得在无外力条件下持续增加对象与流体的总动能。

#### Scenario: 移动物体受到阻力
- **WHEN** 完全浸没的对象相对静止流体水平运动
- **THEN** 对象收到与相对速度相反的阻力
- **AND** 邻近流体收到方向相反的动量

#### Scenario: 偏置浸没产生姿态恢复
- **WHEN** 矩形或凸多边形对象以倾斜姿态部分浸没且浮心不通过质心
- **THEN** 浮力分布产生与力臂一致的扭矩
- **AND** 对称平衡姿态下不会凭空产生持续同向扭矩

### Requirement: 流体与物体双向交换动量
施加到对象的浮力和阻力 SHALL 以相反冲量按 SPH 权重分配给邻近粒子。对一次没有外部脉冲的耦合子步，对象与受影响粒子的总线动量变化 MUST 在配置容差内相互抵消；容器或重力等外力贡献 MUST 在诊断中单独核算。

#### Scenario: 对象推开流体
- **WHEN** 外部系统推动一个浸没对象穿过流体
- **THEN** 对象将动量传递给周围粒子并形成尾流或位移
- **AND** 流体不会只对对象施力而完全不受反作用

#### Scenario: 耦合动量诊断
- **WHEN** 测试在关闭重力、容器反作用和其他外力后推进一个物体流体耦合子步
- **THEN** 对象冲量与粒子总反冲量之和在数值容差内为零

### Requirement: 刚体适配遵守 Godot 物理阶段
Godot 适配层 SHALL 在 Godot 4.6.3 的物理阶段读取刚体运动状态并安全施加求解结果。适配层 MUST 不在普通 `_process` 中直接覆写 RigidBody2D 状态；禁用或移除适配器后，数值核心 SHALL 可以继续在 headless 环境独立测试。

#### Scenario: 对 RigidBody2D 应用流体力
- **WHEN** 适配器在物理 tick 收到某对象 ID 的有限力和扭矩结果
- **THEN** 对应 RigidBody2D 在安全物理阶段接收该力和扭矩
- **AND** 视觉帧率变化不会改变力结果的计算次数

#### Scenario: 对象在求解期间被移除
- **WHEN** 调用方在一个 tick 边界注销对象或对应节点已失效
- **THEN** 后续子步不再为该对象计算或施加流体力
- **AND** 模块不会保留悬空 Node 引用或向错误对象复用旧结果

### Requirement: 浮力交互具有自动化验收
该能力 MUST 提供 headless fixture，至少验证低密度漂浮、高密度下沉、近等密度悬浮、部分浸没连续性、相对运动阻力、恢复扭矩和双向动量交换。

#### Scenario: 运行浮力回归套件
- **WHEN** 粒子流体自动化测试入口执行对象交互测试组
- **THEN** 每个物理规律 fixture 都以明确数值容差判定成功或失败
- **AND** 测试失败会使总测试进程返回非零退出码
