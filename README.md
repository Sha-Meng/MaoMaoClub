# MaoMaoClub

MaoMaoClub is a Godot indie game project configured for Codex-assisted
development.

## Engine

- Godot 4.6.3 stable
- Exact build: 4.6.3.stable.official.7d41c59c4

The pinned engine version is defined in `AGENTS.md`, `.godot-version`, and
`.agents/docs/godot-version.md`.

## Codex Skills

- Project entry point: `AGENTS.md`
- Godot entry point: `.agents/skills/maomao-godot/SKILL.md`
- Production workflow: Codex Game Studios under `.agents/skills` and `.claude`
- Godot expertise: selected `gd-agentic-skills` under `.agents/skills`
